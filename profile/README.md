# ClipboardFusion Pro

> ClipboardFusion Pro keeps reused clips on one Windows desk: open the clipboard history, run the text macros, and leave clip rules on the same desk clipboard.

## Four Beats

1. **Name the desk.** Give the ClipboardFusion Pro desk clipboard a short title before you overwrite a clip.
2. **Pin the live clips.** Keep current items on ClipboardFusion Pro clipboard history and leave unused macros aside.
3. **Check the rules.** Read ClipboardFusion Pro clip rules before you archive a text macro.
4. **Close the loop.** Clear finished clips so the next ClipboardFusion Pro visit does not start with a search.

## First Questions

**Does ClipboardFusion Pro replace every other program?**
No. ClipboardFusion Pro sits beside the editor, browser, and files you already use.

**Can two people share one computer?**
Yes. Each person keeps a separate ClipboardFusion Pro profile.

**What should a new user try first?**
One small ClipboardFusion Pro clip today, then the same clip rules tomorrow.

## Who Sits Down at ClipboardFusion Pro

- **History** — items stay on ClipboardFusion Pro clipboard history.
- **Macros** — phrases stay on ClipboardFusion Pro text macros.
- **Rules** — filters stay on ClipboardFusion Pro clip rules.
- **Desk clipboard** — the name stays on one ClipboardFusion Pro board.
- **Handoff** — the next person can read the ClipboardFusion Pro note without a tour.

## Field Note

ClipboardFusion Pro is easier to trust when the desk clipboard stays smaller than the folder it came from. A named desk shows what is active, the history pins show what you will paste today, and the closing note tells the next person which rule changed.

## One Real Pass

Pick a clip set that already has a name. Open it in ClipboardFusion Pro, keep only those items on the history, and finish one text macro you can see.
